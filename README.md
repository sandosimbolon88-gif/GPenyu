# GPenyu — Pulang ke Banyuwangi

Game edukasi konservasi penyu untuk program Bakti Lingkungan, Bakti BCA.

## Pilih versi

| Versi | File / folder | Keterangan |
| --- | --- | --- |
| **Versi 1 — Original** | [versi-1-original/](versi-1-original/) | Salinan lengkap game pertama, beserta seluruh file pendukungnya. |
| **Versi 2 — Lampiran baru** | [pulang-ke-banyuwangi-v2.html](pulang-ke-banyuwangi-v2.html) | File HTML dari lampiran, disimpan persis seperti aslinya. |

Kedua versi disimpan terpisah. Isi game versi 1 tidak digabung atau ditimpa oleh versi 2.

## Cara membuka

- **Versi 1:** unduh repo, lalu buka `versi-1-original/games/penyu/index.html`. Petunjuk lengkap ada di [README versi 1](versi-1-original/README.md).
- **Versi 2:** unduh `pulang-ke-banyuwangi-v2.html`, lalu buka file tersebut di browser laptop/PC.

## Arsip versi pertama

Folder `versi-1-original` adalah salinan utuh dari [game pertama yang sudah tersimpan di repo](https://github.com/sandosimbolon88-gif/GPenyu/tree/52e90efb3b4ce29cfe5fffa669c8c9bf22084522). Nama dan isi file di dalam folder tersebut dipertahankan.
